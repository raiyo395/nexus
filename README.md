# Nexus DeFi Dashboard

A modern multi-chain DeFi dashboard built with React, TypeScript, Tailwind CSS, Wagmi, and Viem.

## Features

- Multi-chain portfolio overview
- Wallet connection
- Live wallet balances
- Asset allocation
- Transaction state tracking
- Pending transaction handling
- Signature error handling
- Responsive UI

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Wagmi
- Viem
- Vite
