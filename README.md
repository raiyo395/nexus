# Nexus DeFi Dashboard

A Web3 dashboard built with React, TypeScript, Tailwind CSS, wagmi and viem. Connect a wallet, see its balance, and send transactions on the Sepolia testnet.

**Live demo:** https://nexus-chwr.vercel.app/

## Features

- Wallet connection with support for multiple wallet providers
- Reads the connected wallet's Sepolia ETH balance from the chain
- Transaction state tracking
- Pending transaction handling
- Signature rejection handling
- Responsive UI

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- wagmi
- viem
- Vite

## Run locally

1. Install dependencies with `npm install`
2. Start the dev server with `npm run dev`
3. Open the local URL in a browser with a wallet extension such as MetaMask, switched to the Sepolia network

You can get free Sepolia test ETH from any Sepolia faucet.
